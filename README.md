# vinumkb: база знаний по подбору вина

Веб-приложение на Flask: справочник по вину и гастрономии с экспертной системой подбора. Пользователь выбирает блюдо, тип вина и бюджет, а система применяет продукционные правила сомелье и объясняет, почему выбраны именно эти вина.

## Возможности

- **Журнал**: 36 статей по пяти темам (гастрономия, основы дегустации, сервировка, сорта винограда, регионы и стили) с советами сомелье.
- **Закладки**: избранное и недавно прочитанные статьи, хранятся в браузере.
- **Поиск**: по винам, статьям и понятиям, с фильтрами по типу вина и разделу.
- **Глоссарий**: 24 понятия предметной области с поиском.
- **Онтология**: просмотр понятий и связей между ними (`is_a`, `pairs_with`, `balances` и др.) с переходом по связям и фильтром по типу отношения.
- **Что к столу**: экспертная система, 20 продукционных правил вида «ЕСЛИ блюдо и тип вина, ТО рекомендация с объяснением». Если правила нет, включается семантический вывод по связям вин с блюдами.
- **Винный погреб**: каталог из 52 вин с ценами в BYN, температурой подачи, бокалом, ароматами и сочетаниями с едой, у каждого вина карточка с «семантическими триплетами».
- **Видео**: подборка роликов YouTube по темам журнала, клик по карточке открывает YouTube.
- **Замеры**: измерение скорости поиска и логического вывода (100 запросов) и журнал запросов сессии.

## Технологии

- Python 3, Flask
- SQLite (встроена в Python), база знаний в реляционном виде
- Jinja2-шаблоны, чистые HTML и CSS, без внешних библиотек
- Иллюстрации нарисованы в SVG, фото можно подключить своими файлами

## Запуск

Нужен установленный Python 3.9 или новее.

```bash
# 1. Клонировать репозиторий
git clone <адрес-репозитория>
cd vinumkb

# 2. (по желанию) создать виртуальное окружение
python -m venv .venv
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Linux / macOS:
source .venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить
python app.py
```

Откройте в браузере: http://127.0.0.1:5000

Если в PowerShell не выполняется активация окружения, один раз выполните `Set-ExecutionPolicy -Scope Process Bypass`.

### Запуск в VS Code

1. File → Open Folder, выбрать папку `vinumkb`.
2. Открыть терминал (Ctrl+`).
3. Выполнить `pip install -r requirements.txt`, затем `python app.py`.
4. Остановить сервер: Ctrl+C.

## База данных

Данные хранятся в SQLite. Если файла `vinumkb.db` нет, при запуске он автоматически создаётся из `vinumkb.sql`.

| Таблица | Содержимое |
|---|---|
| `wines`, `wine_aromas`, `wine_foods` | вина, их ароматы и сочетания с блюдами |
| `articles` | статьи журнала |
| `concepts`, `relations` | понятия онтологии и связи между ними |
| `rules`, `rule_wines` | продукционные правила и вина, которые они рекомендуют |
| `videos` | видео с YouTube |

Править данные можно в программе DB Browser for SQLite (открыть `vinumkb.db`) или в тексте `vinumkb.sql`. После правки `vinumkb.sql` удалите `vinumkb.db`, и база пересоздастся при следующем запуске.

Пример: заменить ссылку у видео.

```sql
UPDATE videos SET url = 'https://www.youtube.com/watch?v=XXXX' WHERE id = 1;
```

## Фотографии

Фото вин и блюд в репозиторий можно не добавлять. Для вина или блюда без фото показывается нарисованная иконка. Чтобы подключить своё фото, положите файл в `static/photos/` с именем по номеру:

- вина: `wine_01.jpg` … `wine_52.jpg`, номер равен порядку вина в таблице `wines` (по `id`);
- блюда: `dish_01.jpg` … `dish_10.jpg`.

Форматы: jpg, jpeg, png, webp. Список номеров и названий лежит в `static/photos/СПИСОК_ФОТО.txt`.
